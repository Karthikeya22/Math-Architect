# Complement Learning Commons, keep Math Architect

**Learning Commons is open education AI infrastructure—not a Florida teacher product—and the best hybrid keeps Math Architect’s pin → quiz → gaps → remedial loop as the product shell while adopting LC Knowledge Graph enrichment, Math Standards Alignment and Graphics Accuracy evaluators, and Agent Skills as additive layers.** What is actually open today centers on machine-readable standards and math learning components (including Florida in the CASE/CGLT jurisdiction set), CCSS-centric progressions and crosswalk Jaccard scores, MIT/Apache SDKs and Agent Skills, plus free Platform API/MCP access—not a single dump of “everything,” and not gated curriculum materials such as OpenSciEd instructional dumps or IM® assessment packs. Marketing on [learningcommons.org](https://learningcommons.org/) can read like a complete classroom AI stack; the docs reveal developer surfaces with framework-versioning traps, per-dimension LLM judges without a composite pedagogy score, and Curriculum Sync as a district LMS pilot rather than an assessment studio. Math Architect already owns Florida B.E.S.T.–rich local metadata (clarifications, misconceptions, tiered instruction) and a closed classroom workflow that LC does not ship. The decision is therefore **complement, not replace**: use LC to ground and evaluate generation; never swap away the local FL corpus or the verified/Anatomy correctness path as source of truth.

## Open roots deliver datasets and gates, not a teacher loop

Learning Commons positions four products—Knowledge Graph, Agent Skills, Evaluators, and Curriculum Sync—as “AI infrastructure” that partners turn into classroom tools, not as an end-user assessment app ([Learning Commons home](https://learningcommons.org/); [Platform launch](https://learningcommons.org/news/ai-platform-launch/)). Knowledge Graph is a structured collection of educational datasets (standards, learning components, progressions, curriculum, instructional guidance) delivered as UTF-8 **JSONL** (`nodes.jsonl` / `relationships.jsonl`), a REST API at `https://api.learningcommons.org/knowledge-graph/v0` with `x-api-key`, and an MCP server—not a public GraphQL surface ([Introduction](https://docs.learningcommons.org/knowledge-graph/understanding-knowledge-graph/introduction); [Local files](https://docs.learningcommons.org/knowledge-graph/using-knowledge-graph/local-files); [API overview](https://docs.learningcommons.org/api-reference/overview)). Entity identity leans on CASE Network UUIDs plus human-readable `statementCode` values (e.g. `3.NF.A.1`) and, since v1.11.0, `alternateStatementCode` for practitioner codes outside CASE ([Standards schema](https://docs.learningcommons.org/knowledge-graph/schema-reference/standards); [Release notes](https://docs.learningcommons.org/knowledge-graph/resources/release-notes)).

On math and science “codes,” the open surface is asymmetric. U.S. academic standards cover **K–12 Math, ELA, Science, and Social Studies for all 50 states and D.C.** from Common Good Learning Tools CASE data, with Florida present in jurisdiction enums and explicitly listed among states with Math Learning Component alignments ([U.S. academic standards](https://docs.learningcommons.org/knowledge-graph/datasets/standards/us-academic-standards); [Math learning components](https://docs.learningcommons.org/knowledge-graph/datasets/learning-components/math-learning-components); [Dataset catalog](https://docs.learningcommons.org/platform/using-the-platform/dataset-catalog)). Primary LC docs reviewed for this research **never brand Florida frameworks as “B.E.S.T.” by name**, so B.E.S.T. inclusion is strongly implied by current-Florida CASE mathematics data and FLDOE adoption, not named on-page ([FLDOE B.E.S.T. Mathematics](https://www.fldoe.org/academics/standards/subject-areas/math-science/mathematics/)). Math Coherence Map progressions are **CCSSM-centric**; science and social studies **crosswalks are unavailable**; there is **no Science Learning Components dataset** analogous to Math LCs; OpenSciEd is NGSS-aligned but publisher-gated with **no REST endpoints** listed ([U.S. academic standards crosswalks](https://docs.learningcommons.org/knowledge-graph/datasets/standards/us-academic-standards-crosswalks); [OpenSciEd](https://docs.learningcommons.org/knowledge-graph/datasets/curriculum/openscied); [API overview](https://docs.learningcommons.org/api-reference/overview)). “Percentages” in the graph are Jaccard similarity on shared learning components (`hasStandardAlignment` scores from **0.0–1.0**), not student performance or universal content-quality scorecards ([Core concepts](https://docs.learningcommons.org/knowledge-graph/understanding-knowledge-graph/core-concepts)).

Evaluators and Agent Skills are the other concrete open roots. Evaluators are **one-dimension-at-a-time LLM-as-judge** tools (Text Complexity, Feedback, Academic Standards, Durable Skills, Graphics) with MIT-licensed code, CC BY 4.0 prompts/settings, and published Python/TypeScript SDKs (`pip install learning-commons-evaluators`, `npm install @learning-commons/evaluators`) ([Core concepts](https://docs.learningcommons.org/evaluators/understanding-evaluators/core-concepts); [Licenses](https://docs.learningcommons.org/evaluators/resources/licenses); [PyPI](https://pypi.org/project/learning-commons-evaluators/)). **Math Standards Alignment** (first release June 30, 2026) pulls Knowledge Graph learning components and returns per-component aligned booleans plus **Aligned count / Total count**—explicitly **no single composite score**—and is not validated for grading or placement ([Math Standards Alignment](https://docs.learningcommons.org/evaluators/academic-standards-evaluators/math-standards-alignment); [PyPI v1.0.0](https://pypi.org/project/learning-commons-evaluators/1.0.0/)). **Graphics Accuracy** (first release October 14, 2026) returns pass/fail on whether a math graphic supports an accompanying claim ([Graphics Accuracy](https://docs.learningcommons.org/evaluators/graphics-evaluators/graphics-accuracy)). Agent Skills ship four Apache-2.0 K–12 skills—including math-only **K-12 Check for Understanding**—installable via `npx skills add learning-commons-org/agent-skills` into Claude Code, Cursor, or Codex, optionally grounded on Knowledge Graph MCP ([Agent Skills introduction](https://docs.learningcommons.org/agent-skills/understanding-agent-skills/introduction); [Quickstart](https://docs.learningcommons.org/agent-skills/getting-started/quickstart); [LICENSE](https://raw.githubusercontent.com/learning-commons-org/agent-skills/main/LICENSE)). Public GitHub activity concentrates in `learning-commons-org/knowledge-graph` (~**159** stars), `evaluators` (~**85**), and `agent-skills` (~**38**) as of mid-October 2026 ([GitHub org repos API](https://api.github.com/orgs/learning-commons-org/repos)). Curriculum Sync, by contrast, is a **district-facing LMS loader** (Canvas and Google Classroom signals in hiring materials) with **no developer docs section in `llms.txt` and no public Sync repo**—pilot/partner territory, not a self-serve SDK ([Curriculum Sync](https://learningcommons.org/curriculum-sync/); [docs llms.txt](https://docs.learningcommons.org/llms.txt); [Edtech.com job posting](https://www.edtech.com/jobs/product-manager-curriculum-sync-9568)).

## Marketing completeness dissolves under catalog caveats

A student or professor skimming only the homepage can reasonably infer a turnkey stack: open standards for every state, evaluations that measure pedagogical quality, agent skills that teach, and curriculum that syncs into LMS. The documentation undercuts that reading at several points that matter for Florida math products. First, jurisdiction plus subject filters are **not enough**—builders must select the **current** framework (`isCurrent=true`) because old frameworks remain in the graph ([U.S. academic standards](https://docs.learningcommons.org/knowledge-graph/datasets/standards/us-academic-standards)). Second, “aligned to a standard” in Math Standards Alignment can mean covering **1 of 4** learning components while still tagging the parent code; LC itself warns that raw count ratios are ambiguous without knowing intended target components ([Math Standards Alignment](https://docs.learningcommons.org/evaluators/academic-standards-evaluators/math-standards-alignment)). Third, large parts of the Evaluators suite remain literacy- and writing-feedback–shaped (SAP Qualitative Text Complexity; Quill Productive Coaching); math-specific shipped tools are narrower and newer, and docs still leave humans in the loop for high-stakes decisions ([Text Complexity introduction](https://docs.learningcommons.org/evaluators/text-complexity-evaluators/introduction); [Feedback introduction](https://docs.learningcommons.org/evaluators/feedback-evaluators/introduction); [Core concepts](https://docs.learningcommons.org/evaluators/understanding-evaluators/core-concepts)).

Access and cost also diverge from “free open everything.” Open JSONL covers open datasets under CC BY 4.0 / CC0-style licenses; **gated** publisher content (IM instructional/assessment materials, OpenSciEd) requires agreements and catalog language that downloads become available in **Fall 2026** ([Dataset catalog](https://docs.learningcommons.org/platform/using-the-platform/dataset-catalog); [License](https://docs.learningcommons.org/knowledge-graph/resources/license)). Platform API keys are free-account gated; Evaluators still need **caller-owned** Google/OpenAI/Anthropic keys, and Academic Standards evaluators additionally need a Learning Commons key—graphics images go to the caller’s model provider, not to LC servers ([Quickstart](https://docs.learningcommons.org/evaluators/getting-started/quickstart); [Graphics Accuracy](https://docs.learningcommons.org/evaluators/graphics-evaluators/graphics-accuracy); [API keys](https://docs.learningcommons.org/platform/using-the-platform/api-keys)). Agent Skills are lesson plan, differentiation, lesson prep, and short math CFU packages—not a session product with gap analysis and remedial slide decks ([Agent Skills](https://docs.learningcommons.org/agent-skills/understanding-agent-skills/introduction)). Curriculum Sync’s marketing (“load & customize curriculum into your LMS”) describes district co-design, not teacher quiz generation ([Curriculum Sync](https://learningcommons.org/curriculum-sync/); [For School Districts](https://learningcommons.org/for-districts/)). Older GitHub README wording that REST/MCP were private-beta-only also conflicts with September 2026 Platform launch messaging; builders should trust current docs and launch posts over stale README snippets ([Platform launch](https://learningcommons.org/news/ai-platform-launch/); [knowledge-graph repo](https://github.com/learning-commons-org/knowledge-graph/)).

What marketing therefore overclaims, relative to roots, is the composite vernacular of “everything including math codes, science codes, percentages, evaluations.” The accurate translation for a Florida math architect is **yes** to queryable math standards codes and Florida-listed learning-component alignments, math alignment evaluators, open Agent Skills, and Jaccard/component-coverage percentages; **qualified yes** to science framework codes; **no** to science LCs, science crosswalks, open OpenSciEd dumps without publisher access, state-native coherence progressions for Florida, a universal pedagogy percentage, or a ready-made pin → practice → diagnose → remediate product.

## Math Architect already owns the Florida classroom differentiator

Math Architect’s north star is a Florida classroom teacher workflow: pin a B.E.S.T. standard, generate aligned practice, diagnose gaps, and open remedial slides in one session—the closed loop stated in the project’s product brief. Local processed data encodes **Mathematics (B.E.S.T.)** codes such as `MA.K.NSO.1.1` with clarifications, glossary terms, misconceptions, tiered instruction, instructional tasks, and horizontal coherence edges—field richness that CASE tree overviews do not advertise as core StandardsFrameworkItem payload ([U.S. academic standards](https://docs.learningcommons.org/knowledge-graph/datasets/standards/us-academic-standards)). That asymmetry is the strategic hinge: LC can refresh codes, supply granular learning components, CCSS crosswalks, SAP Coherence Map edges, and the Eedi Misconceptions Graph (catalogued as CC BY 4.0 math misconceptions infrastructure) ([Dataset catalog](https://docs.learningcommons.org/platform/using-the-platform/dataset-catalog); [License](https://docs.learningcommons.org/knowledge-graph/resources/license)), but treating Knowledge Graph as a drop-in replacement for the local FL corpus risks stripping CPALMS-style pedagogy joins that make the studio teacher-useful.

On generation quality, LC and Math Architect solve overlapping but non-identical problems. LC Math Standards Alignment judges whether a question covers a standard’s **learning components**; LC Graphics Accuracy judges whether a raster/diagram supports a claim ([Math Standards Alignment](https://docs.learningcommons.org/evaluators/academic-standards-evaluators/math-standards-alignment); [Graphics Accuracy](https://docs.learningcommons.org/evaluators/graphics-evaluators/graphics-accuracy)). Math Architect’s mainline path already runs schema sanitization and figure vision verify; the verified-question worktree adds deterministic solvers, an Anatomy mechanism registry, and offline golden gates that assert mathematical answer correctness without LLM judgment—authority LC evaluators explicitly disclaim for grading and placement. The honest mapping is therefore complement on alignment and raster fidelity, and **do not replace** deterministic solvers or Anatomy for registry-bound visuals. Agent Skills’ Check for Understanding is the closest LC generation artifact to quiz items, yet it still targets short formative CFU HTML outputs rather than Math Architect’s gap → remedial slides productization ([K-12 Check for Understanding](https://docs.learningcommons.org/agent-skills/skills/k12-check-for-understanding)). Curriculum Sync remains out of scope unless the product expands into district LMS curriculum operations ([Curriculum Sync](https://learningcommons.org/curriculum-sync/)).

## Adopt LC gates and enrichment; refuse corpus and loop replacement

Highest-leverage incorporation treats LC as **gateway plugins** around the existing studio, not a rewrite of the teacher UX. First, run **Math Standards Alignment** post-generation (and optionally on remedial claims) against pinned `MA.*` codes and Florida jurisdiction—shadow mode first, then fail-closed thresholds the product team chooses, because LC publishes methodology and evaluator-vs-expert accuracy definitions but leaves downstream cutoffs to integrators ([Math Standards Alignment](https://docs.learningcommons.org/evaluators/academic-standards-evaluators/math-standards-alignment); [Monitor quality in production](https://learningcommons.org/resources/monitor-quality-in-production/); [Accuracy](https://docs.learningcommons.org/evaluators/understanding-evaluators/core-concepts/accuracy.md)). Second, add **Graphics Accuracy** beside the existing vision verifier for AI-raster figures, while keeping Anatomy/SVG deterministic paths as authority when the verified pipeline is live ([Graphics Accuracy](https://docs.learningcommons.org/evaluators/graphics-evaluators/graphics-accuracy)). Third, **enrich** the local graph from open KG datasets—math learning components, CCSS crosswalks, Coherence Map progressions, Eedi misconceptions—joined onto local B.E.S.T. codes, with Math Architect JSON/Supabase remaining the Florida classroom source of truth ([Local files](https://docs.learningcommons.org/knowledge-graph/using-knowledge-graph/local-files); [Math learning components](https://docs.learningcommons.org/knowledge-graph/datasets/learning-components/math-learning-components)). Fourth, borrow Agent Skills (especially CFU and Differentiation) as prompt packs and pedagogy scaffolds feeding remedial copy, without replacing Assessment studio session flow ([Agent Skills introduction](https://docs.learningcommons.org/agent-skills/understanding-agent-skills/introduction)). Fifth, defer Curriculum Sync.

Risks that should shape rollout are concrete. Replacing the local corpus without a field-parity audit can erase Florida-specific instructional guidance that teachers rely on in-session. Evaluator defaults (e.g. Claude Haiku 4 for Math Alignment; Gemini for Graphics) plus multi-provider keys create operational coupling even though code licenses are open ([Math Standards Alignment](https://docs.learningcommons.org/evaluators/academic-standards-evaluators/math-standards-alignment); [Quickstart](https://docs.learningcommons.org/evaluators/getting-started/quickstart)). Platform maturity is real but young—2025 rebrand through September 22, 2026 Platform GA messaging—so version-pin SDKs and JSONL export versions ([Platform launch](https://learningcommons.org/news/ai-platform-launch/); [Scaling Proven Learning Practices](https://learningcommons.org/news/scaling-proven-learning-practices/)). Overwriting working figure or golden-gate pipelines to chase LC branding would discard measured in-house investment for directional LLM judges that LC itself says should not automate high-stakes decisions alone ([Core concepts](https://docs.learningcommons.org/evaluators/understanding-evaluators/core-concepts)).

The replace-versus-complement verdict, stated without hedging: **complement is the correct product strategy; replace is wrong for the teacher loop and for the Florida standards corpus; the only justified “replace” is swapping prompt-only alignment hope for LC Math Standards Alignment as an explicit quality gate—not as the generator.** Best hybrid architecture keeps Coherence atlas → Pin `MA.*` → Quiz → Gaps → Remedial slides; keeps local FL pedagogy metadata; merges verified QuestionPlan/Anatomy when ready; composes quality as offline golden correctness (in-house authority) plus LC learning-component alignment (shadow→gate) plus in-house vision plus LC Graphics Accuracy for rasters; and uses Agent Skills only as adjacent pedagogy assists.

## Conclusion

Learning Commons’ open roots are strongest where Math Architect is weakest as a general platform—multi-state CASE standards plumbing, granular math learning components, research-backed LLM evaluators, and reusable pedagogy skills—and weakest where Math Architect is already product-defining: Florida B.E.S.T. classroom metadata density and the closed pin → practice → diagnose → remediate session. The hybrid that wins for Florida teachers is therefore not “become Learning Commons” and not “ignore Learning Commons,” but **Math Architect as the product, LC as the open context-and-evaluation layer**, with Curriculum Sync left to district LMS futures and gated science/curriculum dumps treated as optional partnerships rather than foundation.
